# Sales Performance and Profitability Analysis Dashboard

## Project Overview
An interactive Power BI dashboard developed using a practice dataset to analyse sales performance, customer trends, revenue and profitability.

## Tools Used
- Power BI Desktop
- Power Query
- DAX

## Dashboard Pages
1. Sales Performance
2. Sales Trend
3. Customer Analysis
4. Profit and Revenue
5. Segment Analysis
6. Profitability

## Key Features
- Interactive KPI cards and visualizations.
- Data cleaning and transformation using Power Query.
- Data modelling and relationships.
- DAX measures for business calculations.
- Interactive slicers and drill-through functionality.

## Key DAX Measures
- Total Sales
- Total Profit
- Profit Margin
- Total Orders
- Repeat Customers
- Sales Growth

## Disclaimer
This is a learning and portfolio project created using a practice dataset. It is intended for educational purposes only.
